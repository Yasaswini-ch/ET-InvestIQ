### **Tech Stack**

- **Framework**: Next.js 14 (App Router)
- **AI Engine**: Google Gemini 1.5 Flash-Lite (High-quota optimization)
- **Data Pipeline**: BSE Scraper, NSE JSON API, SEBI RSS, Yahoo Finance v8
- **Visualization**: Lightweight Charts (Candlesticks), Recharts (Portfolio Metrics)
- **Styling**: Tailwind CSS + Custom `liquid-glass` (Premium Dark Fintech UI)

---

### **Getting Started**

1. Clone the repo: `git clone https://github.com/Yasaswini-ch/ET-InvestIQ.git`
2. Install dependencies: `npm install`
3. Add `GEMINI_API_KEY` to `.env.local`.
4. Run locally: `npm run dev`
