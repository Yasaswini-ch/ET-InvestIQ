ET INVESTIQ - TECHNICAL SUBMISSION DOCUMENT (JUDGE VERSION)

SECTION 1 - EXECUTIVE SUMMARY
ET InvestIQ is a full-stack investment intelligence platform for Indian retail investors. The system is designed as a decision layer on top of market feeds, portfolio context, and AI reasoning. Instead of exposing isolated tools, it implements an end-to-end intelligence loop:

Signal Ingestion -> Context Fusion -> Risk-Aware Inference -> Actionable Output -> Behavioral Reinforcement

Primary objective:
Reduce decision latency, reduce avoidable investor mistakes, and increase action quality through portfolio-aware intelligence.


SECTION 2 - PROBLEM DEFINITION
Indian investors typically operate across disconnected sources:
- Broker app for holdings
- News/social channels for narratives
- Manual spreadsheets for planning
- Informal WhatsApp ecosystems for tips

This creates systemic failure modes:
- Delayed response to market-relevant events
- Context-free actions (event not mapped to holdings)
- Behavioral errors (panic exits, SIP pauses, FOMO entries)
- Scam vulnerability

ET InvestIQ addresses these via a unified architecture that combines deterministic computations and model-driven reasoning with resilient fallbacks.

SECTION 5 - AGENT ROLES (LOGICAL, NOT MARKETING)
The system is implemented as role-oriented agent modules:

1. Portfolio Analyst Agent (/api/xray)
- Input: CAS-derived holdings data
- Output: health score, overlap/risk diagnostics, rebalance actions

2. Radar Intelligence Agent (/api/radar)
- Input: BSE/NSE/SEBI event streams
- Output: normalized and ranked high-conviction market signals

3. Market Chat Agent (/api/chat)
- Input: dialogue + market state + optional portfolio context
- Output: risk-aware conversational guidance with follow-up prompts

4. Chart Pattern Agent (/api/charts)
- Input: ticker + OHLCV window
- Output: support/resistance/trend and pattern interpretation

5. Scam Detection Agent (/api/scamcheck)
- Input: unstructured investor message
- Output: risk score + red flags + claim diagnostics

6. Briefing Agent (/api/briefing)
- Input: portfolio context + live market context
- Output: daily actionable briefing object

7. Intelligence Triad (/api/intelligence/*)
- Budget Impact Agent
- Promoter Signal Agent
- Stay-Course Behavioral Agent

8. SIP Planning Engines (/api/sip, /api/sipoptimizer, /api/stress)
- Deterministic financial projection engines
- AI narrative used for allocation reasoning where applicable


SECTION 6 - AGENT COMMUNICATION MODEL
All agents communicate via typed JSON through API boundaries.

Canonical flow:
1. Client submits typed payload.
2. API validates and rate-limits.
3. Deterministic context assembly runs first (feeds, quotes, local context).
4. Inference call executes with route-specific system prompt.
5. If inference fails, deterministic fallback builder returns usable payload.
6. UI consumes payload and renders source chips/loading/empty/error states safely.

Design principle:
Inference is augmentation, not a single point of failure.

SECTION 11 - IMPACT MODEL (QUANTIFIED)
This section provides directional business impact with transparent assumptions.

11.1 Time Saved
Assumptions:
- 3 meaningful decision cycles per month per active investor
- Manual effort: 35 minutes per cycle
- ET InvestIQ assisted effort: 8 minutes per cycle

Math:
- Delta per cycle = 35 - 8 = 27 minutes
- Monthly saved = 3 x 27 = 81 minutes

Result:
- 81 minutes (1.35 hours) saved per active investor/month

11.2 Cost Reduced (Avoidable Loss Reduction)
Assumptions:
- 1 risky tip event/quarter
- Capital at risk/event: INR 25,000
- Potential downside in bad event: 12%
- Prevention probability via Scam Shield + contextual checks: 40%

Math:
- Protected value/quarter = 25,000 x 0.12 x 0.40 = INR 1,200
- Annual protected value = INR 1,200 x 4 = INR 4,800

Result:
- Approx. INR 4,800 annual avoidable-loss reduction per investor (directional)

11.3 Revenue Potential
Assumptions:
- TAM = 14 crore demat accounts
- Reachable user pool = 1% of TAM = 14,00,000
- Paid conversion = 2%
- Subscription = INR 299/month

Math:
- Paying users = 14,00,000 x 0.02 = 28,000
- MRR = 28,000 x 299 = INR 83,72,000
- ARR = 83,72,000 x 12 = INR 10,04,64,000

Result:
- INR 8.37 million MRR, INR 100.46 million ARR under stated assumptions

Note:
These are back-of-envelope impact estimates for strategic validation, not audited forecasts.
